# Организация разработки

Локальное имя проекта: sports-attendance. Основная ветка: main.
Коммит текущего этапа содержит исходный код, конфигурацию, документацию
и проверки. Сгенерированные данные и SQLite исключены из Git и восстанавливаются
командой demo. Удалённая ссылка отсутствует, GitHub-репозиторий не опубликован.

План последующих фактических коммитов:
1. Версионирование исправлений, связи и карантин некорректных данных.
2. Описательная статистика, пропуски, аномалии и календарные эффекты.
3. Витрина признаков по срезу D−7, лаги и оконные признаки.
4. Базовый прогноз, Ridge, случайный лес и временная валидация.
5. Интервалы, сравнение моделей и интерактивный дашборд.
6. Интеграционная проверка, обновление README и материалы защиты.

Не сохранять пароли, токены, персональные сведения и реальные клиентские
выгрузки. Данные включать в дальнейшую публикацию только с указанием
происхождения и условий использования. Модели и дашборд сейчас не готовы.
