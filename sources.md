# Источники и ограничения

Все 3840 исходных записей демонстрационного набора являются синтетическими.
Период: 2021-01-10 — 2025-12-24, 120 матчей одного условного клуба.
Вместимость: 20000; две домашние игры в месяц. Это технический календарь,
а не расписание реальной лиги. Seed=29. Персональных данных нет.

## matches.csv

Одна строка на матч. match_id — ключ; kickoff — начало в UTC;
published_at — время публикации расписания; result_available_at — время
публикации итогов; home_team, away_team, stadium_id — справочные признаки;
capacity — мест; opponent_rating — условная популярность 1–5;
announced_price_rub — объявленная фиксированная цена; final_tickets — чистые
продажи; attendance — фактическое число посетителей; is_synthetic=1.
Результаты доступны только после result_available_at, даже если технически
весь файл уже лежит на диске. В модель D−7 они не подаются.

## ticket_sales.csv

Одна строка на матч и календарный день продаж (30 дней до игры).
event_id — ключ, match_id — связь с матчем; sale_date — день;
available_at — время доступности итогов дня, 23:59:59 UTC;
sold, refunded, net_tickets — количества; gross_rub, refund_rub — суммы.
Снимок D−7 включает только строки available_at не позднее cutoff.
Итоговые продажи равны сумме net_tickets. В демо возвраты меньше дневных
продаж; реальные отрицательные дневные чистые продажи допустимы.

## weather_forecasts.json

Одна запись на матч и выпуск прогноза D−7. forecast_id — ключ;
valid_at — время матча; issued_at — момент выпуска;
temperature_2m — °C; precipitation — мм; source — synthetic_weather_forecast.
Зависимость спроса от этих величин заложена генератором для проверки форматов,
поэтому не является эмпирическим доказательством влияния погоды.

## Open-Meteo

Основной будущий реальный источник погоды: https://open-meteo.com/en/docs
Формат JSON, доступ через HTTPS. Сохранять response, source_url и retrieved_at.
Координаты 55.75, 37.62 — демонстрационная точка Москвы, не реальный стадион.
HTTP: timeout 20 секунд, до 3 попыток, паузы 1 и 2 секунды, повтор для 429/5xx
и сетевых ошибок. Этот коннектор сохраняет сырой снимок, автоматическое
сопоставление с матчами ещё не реализовано.
Архив наблюдений: https://open-meteo.com/en/docs/historical-weather-api
Нужен для EDA; не использовать фактическую погоду будущего дня как известную.

## Правила загрузки

Хеш файла позволяет пропустить полностью неизменный источник. При изменении
файла добавляются только неизвестные ключи. Конфликт содержимого известного
ключа отклоняется атомарно. Это инкрементальная запись; чтение изменённого CSV
остаётся полным. Для больших источников потребуется API с курсором или партиции.
Проверяются локальные ограничения и формат времени. Сквозная сверка сумм
и ссылок между источниками проверена на демонаборе тестами; автоматический
межисточниковый карантин относится к следующему этапу.
